# 🎓 Student Management System

A simple **Java console-based Student Management System** developed using
Object-Oriented Programming concepts.

## ✨ Features

- ➕ Add Student
- 👀 View Students
- 🔍 Search Student
- 🗑️ Delete Student
- 🚪 Exit

## 🛠️ Technologies

- ☕ Java
- 🧩 Object-Oriented Programming
- 📦 ArrayList
- ⌨️ Scanner
- 🛠️ Git & GitHub

## ▶️ How to Run

Compile:

```bash
javac StudentManagementSystem.java
